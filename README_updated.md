## 🚀 Featured Projects

### ☁️ Cloud-Based E-Learning Platform

A multi-role, service-based e-learning application with JWT authentication and AWS deployment, designed around separate student and instructor workflows.

| Layer | Technology |
|---|---|
| Frontend | React.js |
| Backend | Node.js, Express.js, JWT |
| Real-time | Socket.io |
| Database | MongoDB |
| Cloud | AWS EC2, S3, CloudFront, VPC, IAM, CloudWatch |

**Highlights**
- Backend hosted on EC2 within a custom VPC.
- Static assets served using S3 and CloudFront.
- IAM roles and security groups used for access and infrastructure security.
- MongoDB indexing and query projection used for database optimization.

### 🎮 2048 Game — Browser-Based Web Application

A browser-based 2048 game built from scratch using vanilla JavaScript and an MVC structure.

| Layer | Technology |
|---|---|
| Structure | HTML5, CSS3 |
| Logic | JavaScript (Vanilla), MVC Architecture |
| Persistence | localStorage API |

**Highlights**
- Custom tile-merging logic for directional moves.
- Handles game movement and edge cases.
- Best-score persistence using localStorage.
- Works without a backend dependency.
